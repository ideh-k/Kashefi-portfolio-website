VR/AR

This section highlights my AR/VR projects, featuring immersive environments built with Unity and interactive augmented reality designs created using Adobe Aero. These projects focus on blending creativity and technology to deliver engaging and dynamic user experiences.

Dodge and Collect, A Two-Player Unity Game
I designed a two-player game in Unity where players use different keyboard keys to control their characters. The game features a split-screen interface, with cameras following each player as they collect items and dodge moving enemies. If a player falls or hits an enemy, they lose. The game highlights my skills in coding gameplay mechanics, split-screen functionality, and interactive challenges.
3D Pigeon AR Character
In this project, I designed a 3D pigeon character and integrated it into Adobe Aero to create an interactive augmented reality experience. The character is brought to life in AR, allowing users to interact with it in real-world settings. This project has the potential for further development as part of an AR game, where the pigeon could serve as a playable character, adding a fun and engaging element to the gaming experience.
